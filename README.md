# US Federal Tax Brackets 2026

JSON dataset of 2026 US federal income tax brackets per [IRS Revenue Procedure 2024-80](https://www.irs.gov/pub/irs-drop/rp-24-80.pdf).

## Files

- `tax-brackets-2026.json` — full bracket data + standard deductions

## Use Cases

- Tax calculator development
- Personal finance tools
- Educational/academic projects

## Live Calculator

For interactive calculation, visit [Levyio](https://levyio.com/) — free US tax calculators by state and city.
